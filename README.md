# Liste blanche : défi Alyra (mai 2021)

Un contrat qui enregistre des adresses autorisées et les restitue, avec une interface React et web3.

Le contrat (`Whitelist.sol`, Solidity 0.6.11), le front et les migrations viennent tels quels du modèle [whitelist-system-with-heroku](https://github.com/anthonyC77/whitelist-system-with-heroku). Ma part a été le déploiement sur Heroku : `package.json` à la racine, `.slugignore`, `requirement.txt`.

Exercice de formation, non maintenu.
